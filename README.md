🍕 TasteBite - Restaurant Ordering & Table Booking App

A modern and user-friendly mobile application UI/UX design for restaurant ordering, table booking, online payments, and real-time order tracking.

📱 Project Overview

TasteBite is a restaurant service application designed to provide customers with a seamless food ordering and dining experience.

The app allows users to:

Browse restaurant menus
Order food online
Book tables in advance
Make secure payments
Track orders in real time
Manage profile and booking history
